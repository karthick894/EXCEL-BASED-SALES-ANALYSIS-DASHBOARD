# Excel-Based Sales Analysis Dashboard | Gowri Agencies

## Project Overview
This project analyzes sales voucher data from Gowri Agencies using Microsoft Excel. The objective is to transform raw sales data into meaningful insights through data cleaning, PivotTables, PivotCharts, and an interactive dashboard.The dashboard helps identify top-selling products, analyze monthly sales quantity, understand customer performance, and monitor overall sales volume.

## Project Objectives
- Analyze overall sales quantity.
- Identify top-selling products.
- Compare product-wise performance.
- Analyze monthly sales trends.
- Identify high-performing customers.
- Build an interactive Excel dashboard for data-driven decision-making.

## Project Workflow

1. **Data Collection** – Imported the original sales voucher dataset.
2. **Data Cleaning** – Organized and prepared the dataset for analysis.
3. **Data Transformation** – Prepared date and month fields and structured the data.
4. **PivotTable Analysis** – Summarized sales quantity by product, month, and customer.
5. **Data Visualization** – Created PivotCharts to present sales patterns.
6. **Dashboard Development** – Designed an interactive dashboard with KPIs, charts, and filters.

## Key Insights

- Total sales quantity recorded was **80,043**.
- **36W TUBE LIGHT** was the top-selling product, with **7,266 units**.
- **20W LED G LINE BATTEN FITTING** ranked second, with **7,264 units**.
- **60W GLS** ranked third, with **6,239 units**.
- **September** recorded the highest monthly quantity, with **13,802 units**.
- **August** recorded the lowest monthly quantity, with **6,891 units**.
- **OM MURUGA ELECTRICALS** was the top customer by quantity, with **2,690 units**.

## Final Conclusion
The Excel dashboard provides a clear overview of product-wise, customer-wise, and month-wise sales quantity. The analysis helps identify high-demand products, sales trends, and important customers.This project demonstrates how Microsoft Excel can be used to transform raw sales data into an interactive dashboard and actionable business insights.
